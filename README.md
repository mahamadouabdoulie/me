MAHAMADOU ABDOULIE JAWNEH PORTFOLIO
===================================

Files:
- index.html: portfolio homepage
- assets/: local visual assets used by the website
- Mahamadou_Jawneh_CV.docx: CV download

Publish with GitHub Pages:
1. Create a new GitHub repository (or use an existing empty repository).
2. Upload index.html, the assets folder, and Mahamadou_Jawneh_CV.docx to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch.
4. Select the main branch and / (root), then Save.
5. Wait for GitHub Pages to publish the site.

Before publishing:
- Replace the missing professional email and LinkedIn profile details with real details.
- Review the CV's bracketed placeholders (frameworks, data sources, metrics and tools) and add only verified information.
- Confirm that the listed location, dates, certifications and education details are current.
- Add real GitHub repositories, dashboards or project demonstrations where available.

The visual images are illustrative portfolio artwork, not photographs of the CV owner or screenshots of actual client systems.
